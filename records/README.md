# Records README

## Files

- `evaluation_set.csv`: fixed 60-case evaluation set. Do not change after running experiments unless the team reruns every workflow version.
- `results.csv`: generated by `python3 code/run_evaluation.py`, then scored by `PYTHONPATH=code python3 code/score_results.py`. It contains one row per case and workflow version.
- `summary.csv`: generated by `code/score_results.py`. It summarizes automatic scores, calls, latency, false-premise detection, and refusal accuracy.

## Required Experiment Rule

Every workflow version must run on the same evaluation set:

- V0 baseline
- V1 retrieval only
- V2 router + retrieval
- V3 retrieval + verifier
- V4 full workflow
- A1 full without router
- A2 full without verifier
- A3 full with top-k = 2
- A4 full without calculation/formula guard

## Manual Scoring Workflow

1. Run `python3 code/run_evaluation.py` with the chosen API provider.
2. Run `PYTHONPATH=code python3 code/score_results.py` for reproducible automatic scoring.
3. Open `results.csv`.
4. Review representative rows using `docs/scoring_rubric.md` and `docs/evaluation_manual_review.md`.
5. Keep short comments for representative success and failure cases.
